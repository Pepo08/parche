# Código de conducta

En los issues, los PRs y cualquier espacio de Parche:

- Tratamos a todas las personas con respeto, sin importar su experiencia, su origen ni nada que no tenga que ver con el código.
- Criticamos el código y las ideas, no a las personas.
- No se aceptan insultos, acoso, comentarios discriminatorios ni la publicación de datos privados de otra persona.
- Quien mantiene el proyecto puede editar o borrar comentarios y bloquear a quien no cumpla estas reglas.

Para avisar de un problema de conducta, escribí a **hola@getparche.com**. Se responde en privado.

*In English: be respectful, criticize code and ideas rather than people, and no harassment, insults, discrimination or doxxing. Report problems privately to hola@getparche.com.*
